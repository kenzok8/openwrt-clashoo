故障排查

下手之前先固定三个事实，不然后面全是猜：

  1. 当前用哪个内核（Mihomo / Smart / Sing-box）
  2. 当前生效的是哪份配置文件
  3. 当前运行模式是 Fake-IP、TUN 还是 Mixed

健康检查不通过

概览页的健康检查分 DNS、显式代理、透明代理三项。哪项红就从哪项查起：

  • DNS 不响应 —— 看 DNS 监听端口有没有被占、上游 DNS 是否可达
  • 显式代理端口不通 —— 内核没起来，或者端口被别的插件占了
  • 透明代理规则没生效 —— nftables 规则没写上，重启服务再看
  • 也可能是节点本身挂了，或配置与当前内核不匹配

顺序：看核心日志 → 切回 Fake-IP 试 → 换个已知可用的节点或配置 → 重启服务。

国内通、国外不通

  • 节点不可用，或策略组选到了死节点
  • DNS 能解析但出站失败 —— 先测显式代理，再测透明代理
  • sing-box JSON 转换后节点协议不兼容

国外通、国内不通

  • 国内域名被错误代理：检查规则与策略组
  • 大陆白名单或 GeoIP 过期
  • DNS 上游不可用，直连域名解析不出来

先更新白名单与 GeoIP，再不行就临时切回默认 DNS 策略排除变量。

TUN / Mixed 不通

ls -l /dev/net/tun

没有这个设备就别折腾 TUN，用 Fake-IP。容器、PVE LXC 还要宿主机放行 TUN。概览里显示「降级运行」就是这个意思：想用 TUN，环境不允许，自动退回兼容模式。

sing-box 起不来

  • JSON 格式错误 —— 用配置编辑页看是否已格式化
  • YAML 转出来的字段不兼容，缺必需项
  • 入站端口与其它插件冲突
  • TUN 与 routing_mark 这类字段冲突

先切回 Fake-IP 排除模式因素，再看核心日志里的 FATAL。

内核下载失败

三条原因占绝大多数：GitHub / 镜像不可达、架构选错、上游 Release 资产改名。换镜像源、核对架构先试。

面板打不开

  • 服务没在跑
  • 面板端口没监听，或配额与其它服务撞了
  • 面板文件没下下来，重新更新面板
  • 浏览器缓存旧资源，硬刷新一次

停不掉服务

异步任务还在跑、内核进程卡住、更新任务占着锁，都会让停止按钮看起来没反应。等几秒刷新状态，或看插件日志；别连着猛点启停。

配置改坏了

去 系统 → 备份与还原：

  • 导出过备份 —— 「导入还原」回到那一份
  • 没备份也找不到原因 —— 「还原默认配置」重置设置，订阅与配置文件保留

具体按钮含义见系统维护。
