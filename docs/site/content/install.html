安装与升级

安装包分两层：clashoo（内核 + 服务脚本 + 默认配置）和 luci-app-clashoo（LuCI 界面 + 中文翻译）。24.10 用 .ipk，25.12 用 .apk，脚本会自己判断。

一键安装

以 root 执行。大陆推荐走 jsDelivr 镜像：

wget -O - https://cdn.jsdelivr.net/gh/kenzok8/openwrt-clashoo@main/scripts/install.sh | ash

镜像还没同步到最新脚本时，直连 GitHub：

wget -O - https://raw.githubusercontent.com/kenzok8/openwrt-clashoo/refs/heads/main/scripts/install.sh | ash
jsDelivr 对 @main 有缓存（最长约 12 小时），刚改过的脚本可能延迟生效。安装包下载默认走 GITHUB_PROXY_PREFIX（默认 https://ghfast.top/），失败自动回落直连。换加速站：GITHUB_PROXY_PREFIX=https://你的加速站/ wget -O - … | ash。

脚本校验什么

  • 默认只从签名 feed 装：先比对内置公钥指纹，再用 apk/opkg 校验索引签名与包摘要
  • 指纹不匹配、验签失败、摘要不符 —— 直接停止，不自动降级
  • 只有签名 feed 不可达（纯网络原因）时，才可以用 CLASHOO_ALLOW_GITHUB_FALLBACK=1 显式走 GitHub Release 回退；那条路只核对 GitHub 记录的 SHA-256，不是包签名
CLASHOO_ALLOW_GITHUB_FALLBACK=1 sh install.sh

公钥脚本自己会导入，不用手工操作。要自己核对指纹：

公钥用途
dllkids-feed.pub.pem25.12+ 的 apk 索引签名（ECDSA P-256）
dllkids-feed.pub24.10 及更早的 opkg Packages.gz 签名（usign Ed25519）
curl -fsSLO https://down.dllkids.xyz/openwrt-feed/keys/dllkids-feed.pub.pem
curl -fsSLO https://down.dllkids.xyz/openwrt-feed/keys/dllkids-feed.pub
sha256sum dllkids-feed.pub dllkids-feed.pub.pem

软件源安装与升级

wget -qO- https://down.dllkids.xyz/openwrt-feed/openwrt-feed-setup.sh | sh

脚本会检测 SDK 版本与架构、下载对应公钥、写源配置、刷索引，最后 apk add / opkg install。之后升级只走系统包管理器：

apk update && apk upgrade            # 25.12
opkg update && opkg upgrade clashoo luci-app-clashoo   # 24.10

源码编译

git clone https://github.com/kenzok8/openwrt-clashoo.git package/openwrt-clashoo
make package/clashoo/compile V=s
make package/luci-app-clashoo/compile V=s

卸载

wget -O - https://raw.githubusercontent.com/kenzok8/openwrt-clashoo/refs/heads/main/scripts/uninstall.sh | ash

卸载会停服务、删包。配置留在 /etc/config/clashoo 与配置文件目录，确认不再用之后手动清理。

配套 App

仓库自带 AI 技能 clashoo-user-guide，把功能说明、双内核内幕和排障经验喂给 AI 助手，让它能回答「某功能怎么开」「为什么不通」「日志报错什么意思」：

npx skills add kenzok8/openwrt-clashoo -a '*'

技能里的 references/ 与本仓库 Wiki 同源，由 CI 自动同步。
