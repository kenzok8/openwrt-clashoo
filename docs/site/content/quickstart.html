快速开始

目标：十分钟内让路由器代理起来。装好插件后进 服务 → Clashoo，菜单没出现就刷新浏览器缓存或重启 LuCI / rpcd。

1. 准备配置

先确认手上有哪种配置：机场给的 Clash / mihomo 订阅（YAML），还是 sing-box JSON。拿不准就先用 YAML —— 兼容性最好。

2. 导入配置

路径：配置 → 配置文件。四种常见做法：

  • 粘贴订阅链接下载
  • 上传本地配置文件
  • 把 YAML 转换成 sing-box JSON
  • 直接导入机场提供的 sing-box JSON

导入后在配置文件列表里点 切换，让这份配置生效。生成类订阅会自动跑 mihomo -t 干跑校验，配置有问题会写不进去。

3. 选内核

路径：概览 → 内核切换。三个选项对应三种配置：

选择什么时候用
MihomoYAML 订阅，普通家庭路由器，默认选这个
Smart配了 Smart 策略组、要用策略权重时
Sing-box手上是 JSON 配置时

切换内核后 Clashoo 会按当前配置重新准备运行环境，不用重装包。

4. 选代理模式

概览底部的运行模式下拉框，含义见代理模式与 DNS。一句话：不确定就 Fake-IP；设备有 /dev/net/tun 且想更完整接管流量，再试 TUN 或 Mixed。

5. 启动

概览页打开 启用服务 开关。然后看三处：

看什么正常表现
运行状态显示运行中
健康检查DNS / 显式代理 / 透明代理三项通过
访问检查字节跳动与 YouTube 都能出延迟分档（<400ms 绿 / <800ms 黄 / 更高红）

再看眼流量监控有没有上下行与活跃连接变化 —— 有数字说明流量真的过内核了。

6. DNS 要不要动

默认配置能跑就先别动。确实要按域名分流、或者遇到 DNS 泄漏，再看代理模式与 DNS 里的 DNS 三块拼图。
