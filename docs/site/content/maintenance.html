系统维护

系统 页面管四件事：组件更新、备份还原、定时任务、日志。组件更新在内核与组件更新里讲，这页讲剩下的。

备份与还原

位置：组件更新卡片下方，三个按钮。

按钮做什么
导出备份把 UCI 设置和订阅 / 上传 / 自定义 / sing-box 配置文件打包成一个 JSON 下载
导入还原选之前导出的备份，一键回到那个时间点
还原默认配置设置重置为出厂默认，订阅和配置文件保留
备份只含配置与设置，不含内核和 GeoIP 这些大文件 —— 那些在「组件更新」里重新下载就行。

两条经验：更新内核、批量改配置之前先导一份；改坏了先「导入还原」，找不到原因再「还原默认配置」。

定时任务

用来定时刷新资源。值得开的：

  • 大陆白名单更新
  • GeoIP 更新

订阅自动更新按需 —— 如果你的订阅是转换类链接，自动更新可能把手工调过的配置覆盖掉，那就关掉它。

日志

日志分插件日志和核心日志，排障时先看核心日志里的 ERROR / FATAL：

系统 → 日志 → 核心日志

存储小的设备建议打开自动清理日志，别让日志把闪存写满。

软件包更新

如果你按软件源安装配了 feed，升级走系统包管理器即可：

apk update && apk upgrade                            # 25.12
opkg update && opkg upgrade clashoo luci-app-clashoo  # 24.10

用一键脚本装的机器没有把 feed 写进源，想要包管理器升级就先跑一遍 feed 脚本。

彻底重来

  1. 导出备份（万一还想回退）
  2. 停服务
  3. 卸载：scripts/uninstall.sh
  4. 确认要清空配置的话，删掉 /etc/config/clashoo 与配置文件目录
  5. 重新安装
