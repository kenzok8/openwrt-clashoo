Clashoo

Clashoo 是 OpenWrt 上的代理管理插件：一套 LuCI 界面，管三种内核（mihomo 稳定版 / Alpha、Smart、sing-box），订阅、分流、DNS、透明代理都在图形界面里点完，不用手写配置文件。

支持 OpenWrt 24.10+，推荐 25.x。装完进 服务 → Clashoo，三个页面：概览（启停、内核切换、健康检查）、配置（订阅、配置文件、DNS、Smart 策略）、系统（组件更新、备份还原、日志、定时任务）。
安装与升级 →一键脚本、签名 feed、卸载 快速开始 →导入订阅、选内核、跑起来 故障排查 →不通先看这一页

它管什么

能力说明
三内核切换mihomo 稳定版 / mihomo Alpha / Smart / sing-box 稳定版 / Alpha，切换不用重装，同一套 UCI 配置两端自动适配
配置管理订阅一键拉取、上传、在线编辑、模板复写（YAML 模板 + 订阅链接）；生成后自动 mihomo -t 干跑校验，坏配置不落盘
DNS 策略Fake-IP / Redir-Host 切换，上游按「默认 / 代理 / 直连 / Fallback」分角色，内置 cn.mrs 域名集，防 DNS 泄漏
透明代理TCP 支持 Redirect / TProxy / TUN，UDP 支持 TProxy / TUN，网络栈 gVisor / System / Mixed；局域网 ACL 可按 IPv4 / IPv6 / MAC 分组
系统与数据组件分开更新（内核 / 内核数据 / 插件本体）、备份还原、面板四选一（Zashboard / MetaCubeXD / YACD / Razord）

两种配置格式，别混用

配置内核典型来源
mihomo YAMLMihomo / Smart机场给的 Clash / mihomo 订阅
sing-box JSONSing-box机场给的 sing-box JSON，或由 YAML 转换而来

sing-box 不能直接吃 mihomo YAML；YAML 转出来的 JSON 也要自己测兼容性。首次使用建议先用 mihomo YAML，兼容性最好。

它不是什么

  • 不是订阅转换器，转换只是附带功能，复杂规则还得靠机场或 Tower 这类工具整理。
  • 不接管内核本体之外的系统代理设置，别和 HomeProxy 等插件同时抢透明代理。
  • sing-box 内核下载到私有目录，不覆盖系统的 /usr/bin/sing-box，所以可以和 HomeProxy 共存装；共存时把 Clashoo 切到「仅内核」并错开监听端口。

从哪里开始

没装过先看安装与升级；装好不知道点哪，看快速开始；起来了但不通，直接跳故障排查。
